## 🧾 Sobre o projeto

Este projeto apresenta a interface de uma livraria digital focada em tecnologia. A página simula a home de uma loja online com navegação por categorias, vitrine de lançamentos e seções de destaque.

O foco principal foi aplicar a abordagem **mobile first**, construir layouts responsivos e integrar bibliotecas externas para componentes interativos.

---

## ✨ Funcionalidades

* 📂 Menu de categorias de tecnologia
* 🎠 Carrosséis interativos de livros
* 🆕 Seção de lançamentos
* 🔥 Seção de livros mais vendidos
* 👩‍💻 Destaque para autora do mês
* 📩 Área de newsletter
* 📱 Layout responsivo para mobile, tablet e desktop

---

## 🛠 Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox
* Media Queries
* Swiper.js
* Git e GitHub

---

## 🎠 Uso da biblioteca Swiper

A biblioteca **Swiper** foi utilizada para criar os carrosséis de livros. Ela permite:

* Navegação por toque
* Paginação interativa
* Adaptação automática para diferentes tamanhos de tela

Isso melhora a experiência principalmente em dispositivos móveis.
